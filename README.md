# Toronto Neighbourhood Explorer

An interactive web application for exploring and comparing Toronto's neighbourhoods across various demographic, economic, and crime metrics.

# Features

- Interactive Map View: Choropleth map displaying various metrics across Toronto neighbourhoods
- Neighbourhood Comparison: Bar chart for direct comparisons between selected neighbourhoods
- Correlation Analysis: 3D scatter plot examining relationships between income, housing prices, and crime rates
- Crime Analysis: Detailed breakdown of crime statistics across neighbourhoods
- Scatterplot Matrix: Multi-dimensional analysis to identify patterns among key neighbourhood metrics
- Detailed Statistics: Comprehensive statistics panel for quick neighbourhood insights

# Data Sources

The application integrates Toronto neighbourhood data including:

- Demographics (population, age, household size)
- Economic indicators (income, housing prices, employment rates)
- Crime statistics (assault, auto theft, break and enter, robbery, theft)

# Required Files
Ensure the following files are in your project directory:

- ```toronto.xlsx```: Contains demographic, economic, and crime data for Toronto neighbourhoods
- ```neighbourhoods.geojson```: GeoJSON file containing Toronto neighbourhood boundaries

# Requirements
- dash
- dash-bootstrap-components
- pandas
- numpy
- plotly
- geopandas
